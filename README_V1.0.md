# L’AUTRE JOUEUR — V1.0

Version finale Safari/Web mobile.

## Lancement

Ouvrir `index.html` dans un navigateur moderne. Le jeu est conçu en priorité pour Safari/iPhone, avec prise en charge des écrans tactiles et des contrôles clavier sur ordinateur.

## Données

La progression, la mémoire de l’Autre, les relations, les habitudes, les secrets et les fins sont stockés localement dans le navigateur via `localStorage`.

Aucun serveur, compte ou service externe n’est nécessaire au fonctionnement du jeu.

## Test réel recommandé

Cette V1.0 est la version destinée au premier test humain réel. Pour un test représentatif, commencer une nouvelle partie sans consulter le code ni les conditions cachées, puis noter les impressions de compréhension, difficulté, comportement de l’Autre, rythme, émotion, frustration et envie de rejouer.

## Limitation connue de la validation automatisée

Les contrôles de cette version ont été réalisés par analyse statique et simulations. Un test physique sur iPhone/Safari et un test humain réel restent nécessaires pour valider le ressenti et le comportement sur appareil réel.
